# Entendendo sobre segurança e identidade no Azure. 

O Azure disponibiliza um serviço de segurança que possibilita ao usuráio ter maior controle das entidades que podem ter acesso 
aos aplicativos e recursos utilizados pela empresa. Este recurso é importante também para o gerenciamento e governança dos serviços utilizados. 
Alguns dos recursos disponíveis são o Logon único, proxy reverso HTTP, autenticação multifaror, Azure RBAC e relatórios baseados em monitoramento de segurança, entre outros.

Estes e outros recursos fazem com que a segurança e privacidade organizacional sejam mantidas, proporcionando maior controle e limitações internas, evitando o acesso indevido 
a recursos e dados, além de evitar atividades suspeitas.
